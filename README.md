# js-dsa

A structured repository dedicated to mastering Data Structures, Algorithms, and competitive programming patterns using modern JavaScript (ES6+).

## 📁 Project Structure

This repository is organized logically by topic and difficulty level:

```text
├── Algorithms/         # Standard algorithmic paradigms (Sorting, Searching, DP, etc.)
├── Data-Structure/     # Custom implementations of core data structures from scratch
└── Problem-Solving/    # Solutions from coding platforms (LeetCode, HackerRank, etc.)
   ├── Easy/            # Beginner-friendly challenges
   ├── Medium/          # Intermediate problem sets
   └── Hard/            # Advanced complex puzzles
```

## 🛠️ Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org) installed on your machine to execute the JavaScript files locally.

### Running a Script
To run any specific solution or script, navigate to the folder or run it directly using Node.js from the root directory:

```bash
node Problem-Solving/Easy/01_practice.js
```

## 🎯 Goals & Objectives
* Implement foundational **Data Structures** (Linked Lists, Trees, Graphs) from scratch.
* Master core **Algorithms** (Divide & Conquer, Greedy, Dynamic Programming).
* Optimize code execution by focusing on **Time & Space Complexity (Big O Notation)**.
